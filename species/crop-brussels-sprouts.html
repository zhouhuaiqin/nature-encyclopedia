抱子甘蓝 Brassica oleracea var. gemmifera

十字花科二年生草本，茎高直立、叶腋结出密集的小叶球，形似迷你卷心菜，是欧美冬季常见的蔬菜。

物种志

抱子甘蓝为十字花科芸薹属二年生草本，是甘蓝的一个变种，株高 0.6–1 米，茎直立粗壮。叶片大，蓝绿色，具长柄，螺旋状排列。叶腋处形成直径 2–4 厘米的小叶球，每个叶球由层层包裹的叶片构成，一株可结 40–80 个。第二年抽薹开花，花黄色，四瓣，总状花序。

抱子甘蓝原产欧洲地中海沿岸，由甘蓝在比利时一带选育而成，故英文名含“布鲁塞尔”。它耐寒性强，经霜后叶球甜味增加，是欧美圣诞餐桌上的常见蔬菜。小叶球可烤、煎、蒸或切丝沙拉，富含维生素 C 与膳食纤维，但久煮会产生含硫气味。栽培喜冷凉、阳光充足与肥沃土壤，需较长生长期，多育苗移栽，生长期追肥 2–3 次，摘除下部老叶可促进叶球膨大。

形态与习性

  • 原产地欧洲地中海沿岸，比利时一带选育而成
  • 株高0.6–1 米，一株可结 40–80 个小叶球
  • 叶球直径 2–4 厘米，形似迷你卷心菜
  • 用途烤、煎、蒸或切丝沙拉，富含维生素 C
  • 栽培喜冷凉耐寒，育苗移栽，生长期追肥
  • 采收自下而上分批采摘成熟叶球

趣味知识

  1. 抱子甘蓝的叶球长在叶腋，自下而上依次成熟，采收也要从下往上分批进行。
  2. 经霜打后叶球中的淀粉转为糖，味道明显变甜，这是冬季采收的原因。
  3. 它和卷心菜、西兰花、羽衣甘蓝都是同一个物种甘蓝的不同变种。
  4. 小叶球久煮会释放硫化物产生气味，短时间高温烤制风味最佳。
